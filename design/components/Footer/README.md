# Footer

On `ground`, closing every page:

1. **Join the list** (columns 1–5): an [Input](../Input/README.md) with an uppercase `eyebrow` label and the arrow as submit; the underline turns `gold` on focus (the focus ring is the one gold that never counts). Shown only when the store's newsletter is switched on **and** an address has somewhere to go. "You’re on the list." replaces it once sent.
2. **Three link columns** (columns 7–12): Shop (the Categories that have products, then Shop all), Brand (Our story, then each Drop as "War drop"), Help (the store's published policy pages). Heads in `eyebrow`, `ink-faint`; links in `small`, `ink-muted`, lit to `ink` on hover, 32px tall.
3. A **`line` hairline above the columns** and another **above the legal line**: © year and name on the left, "Play with purpose." on the right, in `small` `ink-faint`.
4. The **wordmark**: TEMPERED in Bodoni Moda (optical size 96), outlined with no fill, stretched edge to edge. Drawn in `line-strong`, not gold, because the footer shares the last screen with whatever gold the page ends on. Its stroke thickens on a phone to stay a visible hairline. Decoration only (`aria-hidden`).

There is no lockup and no giant Cormorant wordmark. Below 1024px everything stacks; the three link columns stay side by side.
