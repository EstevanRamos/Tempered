# MobileMenu

What the word "Menu" opens below 1024px: a full-screen sheet on `ground`. A bar the height of the header carries the mark (home) and the word "Close". Beneath it, the three doors (Shop, Collections, Our story) set in `display-l`, uppercase, each an 80px row over a `line` hairline; hover dims a row to `ink-muted`. Below the doors, the utility words in `label`: Account (or Orders, Account, Sign out when signed in).

It is a modal dialog: focus moves in, Tab is trapped, Escape and Close return focus to the Menu button, and the page behind does not scroll. It fades in over 200ms (instantly with reduced motion). No gold beyond the mark.
