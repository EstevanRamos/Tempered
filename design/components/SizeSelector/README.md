# SizeSelector

Square 44px size chips on a `line-strong` hairline. Selected fills `ink`; out-of-stock sizes are disabled, struck through in `ink-faint`.

Inputs: `sizes` (strings or `{label, value, disabled}`), `label` (default "Size"), and `value` + `onChange` or `defaultValue`. Pair with a "Size guide" `TextLink` (muted) to the right of the legend.
