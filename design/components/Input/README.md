# Input

An underline field: uppercase label above, a `line-strong` hairline below that turns `gold` on focus and `danger` on error. No box, no fill.

Inputs: `label`, `placeholder`, `type`, and either `hint` or `error` (error replaces hint). Pass `submitLabel` for single-field forms (newsletter) to show the arrow submit button. Stack fields with `space-6` between; max width 420px.
