# TextLink

The tracked uppercase link with a hairline arrow ("View all →"), underlined in `currentColor` on hover.

Use it for section-level navigation beside a `SectionHeader`, inside tiles, and at the end of a story band. `tone="muted"` (`ink-muted`) for utility links like "Size guide". Set `arrow={false}` for inline utility links. The consumer provides `href` and a 1–3 word label.
