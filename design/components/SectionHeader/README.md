# SectionHeader

Opens every band: optional `eyebrow`, a `heading` in the display serif (uppercase, tracked), a 32px `gold` rule beneath, and an optional trailing `TextLink`.

Inputs: `title`, and optionally `eyebrow`, `action {label, href}`, `align` (`start` for catalogue bands with a trailing link, `center` for statements), `as` for the heading level. Leave `space-12` between the header and the content it introduces.
