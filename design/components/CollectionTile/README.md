# CollectionTile

A full-bleed photograph with a bottom scrim, the collection name in `title` (display serif), a tracked subtitle and an arrow CTA. Text always sits bottom-left (or bottom-right with `align="end"` when the subject sits left).

Inputs: `image` (dark, desaturated, subject away from the text corner), `title`, `subtitle`, `cta`, `href`, optional `height` (default 320px). Tiles sit in a row of three with a 4px seam, or stack full-width on mobile. Text colours inside are fixed to the Night values because the tile is always photographic.
